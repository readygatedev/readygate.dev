Tickets your developers can build, without anyone guessing.

ReadyGate is a Claude Code plugin for product managers. It reads your real codebase, tells you whether a feature fits, asks the product questions only you can answer, and only then writes tickets: user story, scope, business rules and Given/When/Then acceptance criteria QA can test.

Gates, not guesses

Most AI ticket writers fill gaps with plausible inventions. ReadyGate stops at each gap and hands the decision back to you.

Grounded in your code

Every claim about how the product works today cites a file:line. Your product repo stays read-only.

Setting a seller to suspended doesn't stop their payouts. Suspended sellers are still being paid today.

No ticket while a decision is open

One round of product questions, then nothing is written until you say "generate".

Your answer creates two decisions I can't make for you…

Respects past decisions

A decisions file holds your team's standing rules. A feature that breaks one is flagged as blocked, with the reason.

Testable by QA

3 to 8 acceptance criteria per ticket, each proving a named business rule. Plain business language, no code in the ticket.

No codebase yet? Fine.

Greenfield mode turns your idea into a brief and an MVP backlog, with open questions split into "Before MVP" and "Can wait".

FAQ

What do I need?

Claude Code (any paid Claude plan or an API key), git and python3. For screenshots: Claude in Chrome, or Chrome installed.

How do I get Pro after paying?

Your GitHub account is invited to the private readygatedev/readygate-pro repository, usually within a day. Accept the invite, then install with one command in Claude Code.

Can I use it at work?

Yes. The license covers personal and commercial work, for employers and clients. One license per person using it.

Who owns the tickets it writes?

You do, without restriction.

Does it send my code anywhere?

ReadyGate itself has no servers. It runs inside Claude Code on your machine, so your code is handled exactly as Claude Code handles it.
