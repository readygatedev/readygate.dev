From idea to tickets in three steps

You type in plain English inside Claude Code, Anthropic's AI assistant. ReadyGate does the reading; you make the product calls. The replies below are from a real run on the demo project.

1

Check the idea

It reads your product and answers with a clear verdict: already exists, fits, fits with changes, doesn't fit, or blocked.

/pm-discover <your idea>
Fits, with changes. Not today: the reason is saved when a payout fails, but no screen shows it to Sellers, and the text is a raw bank error that can't go on screen as it is.
2

Answer what only you can

One round of product questions about the gaps it found. If an answer contradicts how the product works today, it says so.

Retry deletes the reason (payouts.ts:18), so if the payout fails again, the earlier reason is gone.

It stops where other tools guess

Most AI ticket writers fill gaps with plausible inventions. ReadyGate has gates instead. These are excerpts from real runs on the demo project.

It finds the problem next to the one you asked about

You asked about failed payouts. It read the payout run and found this.

The Payout run doesn't check the Seller at all. Setting status: "suspended" doesn't stop their payouts (sellers.ts:14-20). So suspended Sellers are still being paid today.

It respects decisions your team already made

Asked for an early payout, it checks your decisions file first.

Blocked. pm/DECISIONS.md says the payout run is weekly, Monday 06:00 UTC, a Finance decision. An early payout changes exactly that.

It keeps tickets testable

Every criterion is something QA can check from the screen, including the states people forget.

AC-04Given the Seller opens Payouts, when the page is loading, has no Payouts, or can't load, then they see a loading indicator, a "no payouts yet" message, or an error message with a way to try again.

Works with or without code

Your product repo stays read-only the whole time: no commits, no branches, no edits.

You have a product

ReadyGate reads the code, so every claim cites the exact file and line.

  • /pm-initDetects your repos and sets everything up, asking only what it can't find.
  • /pm-discoverA fit check with a verdict, or "how does this work today?" in plain language.
  • /pm-ticketGap analysis, one round of questions, then tickets.

You have an idea

No code yet: ReadyGate works from your product brief instead.

  • /pm-newTurns your idea into a brief, asking only about what's missing. Never invents the product.
  • /pm-backlogSplits the first version into features in build order, each ready or waiting on a named question.
  • /pm-ticketThe same gates, grounded in the brief. Technical unknowns go to your tech lead.

Pro covers the rest of the loop

Everything in the free plugin, plus pushing to your tracker, prototyping and reviewing what developers ship.

  • Push to your tracker

    Tickets go to Jira, Linear or GitHub Issues after a dry run you approve, with epics, links and screenshots. Nothing is pushed twice; edited tickets become updates.

  • See what needs attention

    A read-only board view, plus tickets that are out of sync with the tracker.

  • Prototype the screens

    A mockup for your approval, then a mock-data UI and checked screenshots. What the screens decide becomes a proposed ticket change.

  • Grade what was shipped

    After developers merge, a summary of what changed, graded A to D against each ticket's rules, with the code as evidence.

  • Gates that are enforced

    Hooks keep the product repo read-only and block ticket or tracker writes until your own message says "generate" or "push".

Questions

I'm not technical. Can I use it?

Yes. You talk to it in plain English inside Claude Code, Anthropic's AI assistant. Installing takes one command, and /pm-init sets up the rest by asking you a few questions.

What do I need?

Claude Code (with a paid Claude plan or an API key), git and python3. For Pro screenshots: Chrome.

What does it cost to run?

It runs on your own Claude Code plan. On API pricing, a feature from idea to tickets typically costs $1–4.

How do I get Pro after paying?

The GitHub account you entered is invited to the private readygatedev/readygate-pro repository automatically. Accept the invite from your GitHub notifications or email, then install it with one command.

Can I use it at work?

Yes. The license covers personal and commercial work, for employers and clients. One license per person using it. Everything it helps you write belongs to you.

Does it change my code or send it anywhere?

It never changes your product code. ReadyGate has no servers of its own: it runs inside Claude Code on your machine, so your code is handled exactly as Claude Code handles it.

Can I get a refund?

Yes, within 14 days. See the refund policy. A refund ends the license and repository access.
